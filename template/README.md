# **PROJECT_NAME**

A production-oriented full-stack Helvetium application generated by `@newfoundcodes/helvetium-boilerplate`.

## Start

```bash
cp .env.example .env
npm install
__ALPS_README_START__npm run dev
```

Open `http://127.0.0.1:__PORT__`. The server uses Helvetium Boot and pages use Helvetium DOM__ALPS_README_DESCRIPTION__.

## Important files

- `server.ts`: loads the environment, registers middleware, and starts Boot.
- `src/routes/paths.ts`: creates the Boot app and registers HTTP + page routes.
- `src/index.tsx`: document template passed to `helvetiumPages()`.
- `src/web.ts`: browser hydration/router entry.
- `src/app/`: page components, shared UI, and the browser-safe page route table.
- `src/routes/handlers/`: endpoint callbacks.
- `src/middlewares/`: middleware factories.
